# Evaluation records

- `experiments.json`: KiTS23/MMWHS cohorts, fold assignments, seeds, and retrieval pools.
- `checkpoints.json`: registered checkpoint metadata and available weight hashes.
- `external_methods.json`: external encoder interfaces and source/weight provenance.

Historical source paths, source-file hashes, and `data:///` or `source:///` identifiers describe the recorded inputs; they are not runnable paths or hashes of the current adapters. Configure local data and weights through YAML as described in the guides below.

See [Reproducibility](../docs/reproduction.md) for configuration and evaluation commands.
