# Evaluation records

- `experiments.json`: KiTS23/MMWHS input, fold, and retrieval-pool definitions, with verification limits.
- `checkpoints.json`: registered checkpoint metadata and available weight hashes.
- `external_methods.json`: external encoder interfaces and source/weight provenance.
- `model_export_manifest.json`: source inventory and attribution for bundled encoder implementations.
- `package_inventory.json`: hashes and byte counts for the public repository files.

See [Reproducibility](../docs/reproduction.md). Historical paper results, table generators, pretraining snapshots, and migration archives are retained locally and are not distributed.
